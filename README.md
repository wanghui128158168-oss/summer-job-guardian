# Summer Job Guardian — 大学生暑期工安全守护 Skill

> 一个专门保护大学生在暑期工、实习、兼职和零工场景中免受招聘陷阱、工资纠纷和现场被骗的 AI Skill。

---

## 为什么做这个 Skill？

每年暑假，大量大学生通过 Boss 直聘、58 同城、小红书等平台找工作。  
但真实场景中经常遇到：

- 到了现场才发现岗位、工资、食宿全变了（bait-and-switch）
- 被要求先交 "保险"、"培训费"、"押金"，干不够天数就不退
- 承诺 "月薪 5500 干 45 天"，实际变成日结且不保证每天有活
- 被拉到外地、身份证被扣、人身自由受限

**这些问题不是 "年轻人不够小心" 就能避免的。**  
大多数学生第一次面对这些情况时，没有判断框架，也没有证据意识，往往在慌乱中做出错误决定。

这个 Skill 就是用来解决这个问题的。

---

## 它能做什么？

### 1. 求职前：帮学生选对工作模式
- 比较 "包吃住"、"自行租房 + 稳定工作"、"灵活兼职" 的真实净收入
- 按可验证性排序求职渠道（学校就业中心 > 政府公共就业 > 雇主官网 > 社交平台）
- 提供直接打电话核实岗位的话术模板

### 2. 事前核验：发现招聘信息里的坑
- **六方地图**：区分发布者、面试者、收款方、签约方、实际用工方、工资支付方
- **五一致性检查**：对比广告、聊天、合同、入职通知、实际工作
- **费用/证件审查**：列出所有费用，要求说明收费主体、金额、发票、退款条件
- **中介核验**：验证中介的法律身份、注册状态、授权范围

### 3. 合同审查：逐条找出高风险条款
- 自动标记雇主单方面变更权、无限期无薪培训、全权扣款权等高风险 clause
- 输出标准化的条款对照表（原文、状态、实际风险、缺失证据、建议措辞）

### 4. 到了现场发现不对：沉没成本决策框架 ⭐ 核心能力
这是大多数同类工具没有的能力。

当学生已经在外地、发现实际工作与承诺严重不符时，Skill 会：

1. **先判断安全**：是否有威胁、拘禁、扣留证件 → 有则立即报警
2. ** bait-and-switch 检测清单**：逐项对比岗位、地点、工资、费用、证件、住宿
3. **沉没成本决策计算**：
   - 继续耗着的真实成本（食宿 + 机会成本 + 收入上下限）
   - 立刻走的成本（已付费用 + 未结工资 + 返程费）
   - 给出理性决策：**即使写-off sunk cost，也应该离开**
4. **去留矩阵**：安全 × 预期净收入二维决策
5. **现场取证清单**：离开前必须拍公司门脸、规则、排班表、收款记录

### 5. 证据收集：录音、截图、聊天记录的操作手册
- **录音指导**：什么时候录、第一句话怎么说、6 个必须录到的关键问题
- **截图/照片标准**：招聘页、聊天记录、支付凭证、合同每一页
- **文件命名规范**：`YYYYMMDD_HHMM_type_description.extension`
- **隐私脱敏规则**：身份证号、银行卡号、家庭住址必须打码
- **法律效力说明**：私下录音在民事纠纷中的一般处理原则

### 6. 事后响应：止损、维权、投诉
- 提供书面退款请求、工资核对请求的模板
- 指导向 12333（人社）、12348（法律援助）、12345（市民热线）反映
- 平台投诉入口和材料准备指引
- 证据包清单和时间线表格模板

## 适用场景

| 场景 | Skill 如何帮助 |
|---|---|
| 看到招聘信息，不确定靠不靠谱 | Verify 模式：六方地图 + 五一致性检查 |
| 收到 Offer / 合同，需要审查 | Review 模式：条款级分析 + 高风险 clause 标记 |
| 已经到现场，发现岗位/工资变了 | On-site 模式：沉没成本决策 + 现场取证 |
| 交了钱但没入职 / 干完活没拿到工资 | Respond 模式：止损指引 + 维权渠道 + 文书模板 |
| 多个 offer 比较，不知道选哪个 | Plan 模式：净收入计算器 + 策略对比 |

##  Skill 的设计原则

1. **安全优先，不搞 "风险评分"**  
   不用 "5 分安全" 这种模糊评分，而是用 `stop now` / `pause and verify` / `continue cautiously` 三级决策。

2. **事实分层，不混淆证据等级**  
   所有信息必须标注为 `verified`、`user evidence`、`recruiter claim`、`inference` 或 `unknown`。

3. **不把文件和品牌当 proof**  
   营业执照、知名品牌、合同、办公室、长得像员工的人，都不能证明这个岗位就是真的。

4. **不用歧视性特征当风险证据**  
   纹身、吸烟、穿着、年龄、口音、性别、举止，都不能用来判断岗位是否靠谱。

5. **不用记忆里的 "事实"**  
   房租、公司状态、证书要求、投诉电话，必须查最新官方来源，不能凭记忆编。

## 配套工具

| 工具 | 用途 |
|---|---|
| `scripts/net_income.py` | 净收入计算器，对比不同工作模式的真实收益 |
| `scripts/compare_terms.py` | 术语比对工具，检测招聘广告、聊天、合同之间的文字变更 |
| `references/evidence-collection.md` | 取证操作手册，教学生怎么录、怎么截、怎么命名 |
| `references/on-site-emergency.md` | 现场紧急决策框架，沉没成本计算 + 去留矩阵 |

---

## 技术架构

- **格式**：纯 Markdown，零外部依赖
- **运行环境**：支持 OpenAI function calling 的 AI Agent
- **路由方式**：根据用户意图自动路由到 Plan / Find / Verify / Review / Monitor / On-site / Respond 七个工作流
- **引用机制**：通过 `references/*.md` 模块化引用，方便持续更新

---

## 与同类工具的区别

| 维度 | Summer Job Guardian | 普通防骗指南 |
|---|---|---|
| 场景覆盖 | 求职前 → 到现场 → 事后维权全链路 | 通常是碎片化的 tips |
| 决策框架 | 沉没成本量化 + 去留矩阵 | "感觉不对劲就撤" |
| 证据指引 | 录音/截图/聊天记录的操作手册 | "记得保留证据" |
| 输出格式 | 标准化安全报告 | 口头建议 |
| 适配性 | 针对中国大陆暑期工场景 | 通用或跨境 |

## 真实案例参考

Skill 里内置了 4 个匿名真实案例，包括：

- **地铁安检收费 + 临时增加证件要求**（交钱后被告知岗位已满，要等半个月培训）
- **保安公司办公室身份 concealed**（公司名称被涂改，大量学生等待但无明确岗位）
- **推荐同学奖励的陷阱**（学生在不知情的情况下变成 recruitment agent）
- **现场 bait-and-switch + 沉没成本 trapping**（5500/45天变成日结不固定，700 块保险/押金被套）

每个案例都包含：事件序列、模式提炼、Skill 应该给出的响应。

## 作者的话

这个 Skill 的灵感来自我朋友弟弟的真实经历：  
被承诺 "5500 干 45 天"，交了 700 块 "保险"，到了现场变成日结且 13 天只干了 3 天，走人则 700 块不退，不走则继续耗着。

我发现市面上没有针对 **"人到现场才发现被坑"** 这个高频场景的系统化工具。  
大多数内容要么是泛泛的 "防骗 tips"，要么是事后法律援助，缺少 **实时决策支持 + 证据操作手册**。

于是我把这个 Skill 做出来了。  
希望它能让更多大学生在遇到类似情况时，知道 **"现在该做什么、录什么、怎么算、去哪反映"**。

如果你也觉得有用，欢迎 Star、Fork、贡献案例。
