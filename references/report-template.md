## Compact Urgent Format

For immediate danger or live payment pressure, respond first with:

```markdown
结论：现在停止［具体动作］。

立即做：
1. ...
2. ...

不要做：
- ...

安全后保存：
- ...
```

Then build the complete report after the user is safe.
