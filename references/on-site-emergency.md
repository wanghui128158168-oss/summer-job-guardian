## Purpose

This reference covers the high-frequency case where the student has already traveled to the work site and discovers that:
- the actual work differs materially from the advertisement or contract;
- unpaid waiting, training, or certificate periods are longer than disclosed;
- living conditions, location, or controlling party have changed;
- the employer or intermediary is pressuring the student to accept new terms, pay additional fees, or recruit others;
- the student feels unsafe, isolated, or unable to leave without losing money already paid.

The skill's non-negotiable rules still apply: personal safety comes first, do not turn documents or brands into proof of legitimacy, and do not use prohibited characteristics as risk evidence.

## Safety Triage On Arrival

Before analyzing income or contract terms, check for immediate danger:
- physical threat, confinement, stalking, coercion, injury, or blocked exit;
- confiscated identity document, bank card, phone, or luggage;
- pressure to pay immediately, borrow money, transfer through a personal account, or complete facial recognition;
- unexpected transport to another city, remote site, hotel, private residence, or vehicle;
- demands to open, lend, sell, or operate a bank account, phone card, social account, or payment account;
- isolation from friends or family, threats for leaving, or instructions to conceal the situation.

If any of the above is happening now, the response is a short safety-first instruction:
1. Move to a public safe place when feasible.
2. Contact a trusted person and share current location and party details.
3. Use current local emergency or police channels.
4. Do not confront the recruiter or investigate secretly while in danger.

Do not ask the student to gather more evidence or negotiate terms before they are safe.

## Bait-And-Switch Detection Checklist

Compare each of the following against the original offer. A material difference is a bait-and-switch indicator.

| Item | Original promise | Current reality | Gap |
|---|---|---|---|
| Job title and duties | | | |
| Exact work site and city | | | |
| Daily hours and rest days | | | |
| Wage basis, amount, and pay date | | | |
| Fees, deposits, or insurance charged | | | |
| Certificates or training required | | | |
| Housing address and conditions | | | |
| Who signs, manages, and pays | | | |
| Start date and guaranteed minimum days | | | |

Treat every newly introduced fee, unpaid period, certificate, location change, or wage condition as unresolved until written and independently verified.

Common bait-and-switch patterns:
- "Full position" turns into "waiting for dispatch" or "placement pending."
- "55 yuan per day" becomes "only when assigned" with few or no assignments.
- "Monthly wage after 45 days" becomes piece-rate or day-rate with no floor.
- "Insurance fee" is described as refundable, then relabeled as training, deposit, or penalty.
- Employer identity changes from a known brand to an unnamed labor company.
- Housing moves from a described dormitory to a hotel, private residence, or distant site with different costs.

## Sunk-Cost Decision Framework

Students often feel trapped because they have already spent money or time to arrive. Make the cost of staying explicit.

### Step 1: Calculate the true cost of staying

| Cost category | Calculation basis | Amount |
|---|---|---:|
| Already irreversible costs (travel, fees, deposits) | Already paid, unlikely to recover | |
| Continuing daily costs (food, lodging, local transport) | Per day x remaining expected days | |
| Opportunity cost (other available work, study, rest) | Estimated foregone income or value | |
| Income floor if staying | Most likely realized wage x days | |
| Income ceiling if staying | Best-case realized wage x days | |
| Probability-weighted expected stay income | (floor x 0.6 + ceiling x 0.4) as example | |
| Net result of staying | Expected income - continuing costs - irreversible costs | |

### Step 2: Calculate the cost of leaving now

| Cost category | Amount |
|---|---:|
| Already irreversible costs (sunk) | |
| Wage already earned but unpaid | |
| Fees or deposits at risk of non-refund | |
| Cost of returning home | |
| Net result of leaving | Sunk cost + unpaid wages + at-risk fees + return cost |

### Step 3: Compare

If staying produces a negative or near-zero expected net outcome and leaves the student in an uncontrolled environment, the rational decision is to leave, even if it means writing off the sunk cost. The skill should state this plainly.

Key principle: do not spend additional money or borrow to recover an earlier payment.

## Stay-Or-Leave Matrix

Use both current safety and expected economics.

| Safety | Expected net income | Decision |
|---|---|---|
| Safe and positive or neutral | Continue with active verification |
| Safe but negative or highly uncertain | Leave; stop further loss |
| Unsafe or confinement | Leave now; safety before money |
| Physical threat, document confiscation, blocked exit | Stop now; contact police or emergency services |

A role that requires the student to recruit classmates, lend accounts, or make unexplained payments in order to leave or recover money is a hard stop.

## On-Site Negotiation Tactics

If the student is safe and wants to attempt clarification before leaving, keep the interaction written and low-pressure.

### When to negotiate
- The student is not physically threatened or confined.
- The discrepancy can be resolved by written confirmation of original terms or a refund.
- The student has a safe place to stay independently and does not need the employer's housing to leave.

### When not to negotiate
- The employer refuses to name the wage payer or contracting party in writing.
- The employer demands additional payment, deposit, or recruitment as a condition for leaving or paying.
- The employer changes location, delays, or pressures the student to move to another site.
- The student feels threatened or isolated.

### Suggested written requests

Clarification request:
> 我于[日期]到达[地点]。此前约定的[岗位/工资/食宿/发薪日]与目前实际安排存在以下差异：[逐项列明]。请贵方于[日期]前以公司名义书面确认：签约主体、实际用工单位、具体岗位、起止日期、工资计算方式、已收费用的性质和退款安排。若无法按原约定安排，请书面说明退费或安置方案。

Refund request for fees:
> 我于[日期]支付了[金额]用于[保险/体检/培训/押金]，当时说明[退款条件]。目前[岗位/工作安排/发薪]与约定不符。请贵方于[日期]前退还上述费用并书面说明依据。若逾期未回复，我将向[12333/12345/12348]及平台反映并保存证据。

Do not threaten criminal labels. Keep every message factual and attributable.

## Evidence-First Departure

Before leaving the site, collect what can be collected without confrontation:
- photographs or videos of the company name on the door, rules, forms, badges, and receipts;
- the exact address, building name, and nearby landmarks;
- names, numbers, and roles of people present;
- any written notice, schedule, or instruction that differs from the original offer;
- a contemporaneous note of what was said, by whom, and in front of whom.

Keep originals untouched. Do not argue, delete, or block anyone before the evidence is preserved. Preserve evidence before returning home.

## Return-Home And Escalation

If the student decides to leave:
- calculate and document all expenses and unpaid wages;
- send the written request for clarification or refund before departure if safe to do so;
- keep transport receipts and record the departure time and location;
- do not sign any retroactive document, settlement, or acknowledgment without reading and understanding every term;
- upon returning home, file complaints through the recruiting platform, local labor inspection, or legal-aid channels as appropriate.

Group cases: if other students from the same batch are in the same situation, compare notes independently, preserve each person's evidence separately, and consider joint complaint only after each person has reviewed their own facts and risks.
